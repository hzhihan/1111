# 升學與職涯趨勢導航系統

Educational and Career Trend Navigation System

## 專案簡介

這是一個幫助學生選擇學術類組、了解科系與職業前景的導航系統。系統提供：
- 學術類組選擇指引（一、二、三類組）
- 適合科系推薦與跨域彈性分析
- 薪資分析與20年預測
- AI取代風險評估
- 學習路徑建議
- 數學A/B影響分析

## 功能特色

### 1. 導航邏輯與架構
- **入口選擇**：選擇一、二、三類組
  - 第一類組細分：文學院、法學院、商學院（標註數A/B適用性）
  - 第二類組：理工學院
  - 第三類組：生醫學院
- **科系頁面**：顯示適合科系及跨域彈性專區
- **功能分流**：選擇「未來職業」或「基本能力」分析

### 2. 核心功能模組

#### 薪資分析儀
- **數據分層**：
  - 地區：北部、中部、南部
  - 學歷：學士、碩士
  - 企業規模：新創、大企業
- **視覺化**：20年薪資預測曲線（使用Chart.js）
- **量化指標**：
  - 壓力指數（1-10）
  - 平均工時（小時/週）
  - 社會貢獻（1-10）
  - AI取代風險（百分比）

#### 未來趨勢地圖
- **技能 vs 職稱**：分析職位核心技能的可轉移性
- **AI抗風險指數**：
  - 高：需要創意、情商、複雜決策（如醫師、教師）
  - 中：人機協作（如工程師、分析師）
  - 低：重複性工作（如基礎行政）

#### 學習路徑圖
- 高中銜接建議
- 證照推薦
- 線上課程建議

#### 數A vs 數B 影響分析器
- 分析不同數學組別對未來選系的影響
- 提供明確的適用性建議

## 技術架構

- **前端框架**：HTML5
- **CSS框架**：Tailwind CSS (CDN)
- **圖表庫**：Chart.js
- **語言**：JavaScript (Vanilla)
- **設計特點**：
  - 響應式設計（支援手機、平板、桌面）
  - 科技感UI設計
  - 清晰的層級架構
  - 流暢的過場動畫

## 如何使用

### 方法一：直接開啟HTML檔案
1. 下載或克隆此專案
2. 使用瀏覽器開啟 `index.html`
3. 開始探索！

### 方法二：使用本地伺服器
```bash
# 使用Python
python3 -m http.server 8000

# 使用Node.js
npx http-server

# 然後在瀏覽器開啟 http://localhost:8000
```

## 使用流程

1. **選擇類組**：在首頁選擇一、二、三類組及子類別
2. **選擇科系**：查看推薦科系與跨域彈性資訊
3. **選擇功能**：
   - **未來職業**：查看薪資分析、趨勢預測、AI風險
   - **基本能力**：查看學習路徑、數A/B影響分析
4. **探索數據**：使用篩選器調整參數，查看不同情境下的分析結果

## 數據說明

- 薪資數據為模擬數據，實際薪資會因個人能力、市場狀況等因素而異
- AI風險評估基於當前技術趨勢分析
- 學習路徑建議僅供參考，應根據個人興趣與能力調整
