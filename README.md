# 升學與職涯趨勢導航系統

Educational and Career Trend Navigation System

## 專案簡介

本系統旨在協助學生了解不同學群、科系的未來發展趨勢，包含薪資分析、職業路徑、AI取代風險評估等功能。

## 主要功能

### 1. 導航邏輯與架構
- **入口選擇**：三大類組選擇（第一、二、三類組）
- **第一類組細分**：文、法、商學群，並標註數學A/B選擇
- **科系推薦**：依據選擇顯示適合科系
- **跨域彈性專區**：提供跨領域學習建議

### 2. 核心功能模組

#### 薪資分析儀
- 分區域數據（北部、中部、南部）
- 學歷分層（學士、碩士）
- 公司規模（新創企業、大型企業）
- 20年薪資預測曲線視覺化
- 附警語說明

#### 量化指標
- 壓力指數
- 平均工時
- 社會貢獻度
- AI取代風險評估

#### 未來趨勢地圖
- 核心技能分析（技能 vs 職稱）
- 技能可轉移性評估
- AI抗風險指數分類：
  - **高**：創意、情商、複雜決策（醫療、心理、高階決策）
  - **中**：人機協作（工程師、分析師）
  - **低**：重複性工作（基礎行政、資料輸入）

#### 學習路徑圖
- 高中銜接建議
- 證照推薦
- 線上課程資源

#### 數學A vs B影響分析器
- 分析不同數學組別對未來選系的影響
- 提供學習建議

## 技術架構

- **前端框架**：純 HTML5 + JavaScript (ES6+)
- **CSS框架**：Tailwind CSS（通過CDN引入）
- **圖表庫**：Chart.js
- **響應式設計**：支援桌面、平板、手機
- **瀏覽器支援**：Chrome, Firefox, Safari, Edge (最新版本)

## 使用方式

### 本地開發

1. 克隆專案
```bash
git clone https://github.com/hzhihan/1111.git
cd 1111
```

2. 啟動本地伺服器
```bash
# 使用 Python 3
python3 -m http.server 8000

# 或使用 Node.js
npx http-server -p 8000
```

3. 開啟瀏覽器訪問
```
http://localhost:8000/index.html
```

### 直接使用

直接在瀏覽器中打開 `index.html` 檔案即可使用（需要網路連線以載入CDN資源）。

## 系統流程

1. **選擇類組** → 第一/二/三類組
2. **細分領域**（僅第一類組） → 文/法/商 + 數學A/B
3. **選擇科系** → 瀏覽適合科系列表
4. **功能選擇** → 未來職業探索 或 基本能力準備
5. **深入分析** → 薪資、趨勢、學習路徑等詳細資訊

## 注意事項

⚠️ **免責聲明**：
- 本系統提供的薪資預測基於歷史數據與產業趨勢
- 實際薪資受個人能力、經驗與市場變化影響
- 所有資訊僅供參考，不構成職業建議
- 建議搭配專業諮詢進行決策
